# دفاع از جزیره خارک

بازی دوبعدی دفاع هوایی، نوشته‌شده با **پایتون و pygame**. بازیکن با پدافند چرخانِ پایین صفحه هواپیماهای دشمن (اف-۱۶ و اف-۳۵) را سرنگون می‌کند تا ۶ مخزن نفت جزیرهٔ خارک را تا پایان ۲ دقیقه نگه دارد. همهٔ متن‌ها فارسی است و بازی هم روی کامپیوتر و هم (با ساخت APK) روی اندروید اجرا می‌شود.

## اجرا روی کامپیوتر

```bash
pip install pygame
python main.py
```

پایتون ۳٫۹ یا بالاتر لازم است. اگر پنجره روی نمایشگر شما بزرگ بود، با کلید `F11` تمام‌صفحه کنید؛ بازی خودش اندازه را با حفظ نسبت تصویر تنظیم می‌کند.

| ورودی | کار |
|---|---|
| کلیک ماوس / لمس صفحه | شلیک پدافند به همان نقطه |
| دکمهٔ سه‌نقطهٔ بالا | فهرست: توقف بازی، ادامه بازی، بازگشت به منو |
| `Esc` یا دکمهٔ برگشت اندروید | باز و بسته کردن همان فهرست |
| `F11` | تمام‌صفحه (فقط کامپیوتر) |
| `M` | بی‌صدا / باصدا (فقط کامپیوتر) |

## قوانین بازی

- هواپیماها از چپ وارد می‌شوند و به راست می‌روند. اف-۱۶ سریع است و با **یک** ضربه سقوط می‌کند؛ اف-۳۵ زره‌دار و کندتر است و **دو** ضربه لازم دارد.
- هر هواپیما یک مخزن را هدف می‌گیرد و پیش از رسیدن به آن بمب می‌اندازد. بمبی که رها شد دیگر متوقف نمی‌شود؛ پس هواپیما را باید پیش از نقطهٔ بمب‌اندازی زد.
- هر مخزن **دو** فرصت دارد: بمب اول آسیب می‌زند، بمب دوم مخزن را منفجر می‌کند. هواپیماهای بعدی به‌ترتیب سراغ مخزن‌های ۱ تا ۶ می‌روند.
- زمان‌سنج از ۲:۰۰ شروع می‌شود. در ثانیه‌های اول فقط چند هواپیمای پراکنده می‌آید و هرچه زمان می‌گذرد تعداد، سرعت و درصد اف-۳۵ بیشتر می‌شود.
- اگر زمان به صفر برسد **می‌برید**؛ اگر هر ۶ مخزن نابود شوند **می‌بازید**. بعد از هر حمله وضعیت مخزن‌ها هم روی جزیره و هم در نوار بالای صفحه (سبز: سالم، نارنجی: آسیب‌دیده، قرمز: نابود) دیده می‌شود.
- مرحلهٔ ۲ سریع‌تر و پرهواپیماتر است و بعد از بردن مرحلهٔ ۱ هم با دکمهٔ «مرحلهٔ بعد» می‌توان رفت.

## ساختار پروژه

```
main.py                 نقطهٔ شروع
buildozer.spec          تنظیمات ساخت APK
.github/workflows/      ساخت خودکار APK با گیت‌هاب
assets/                 لوگو، آیکون، فونت، موسیقی (music/)
game/
  config.py             همهٔ ثابت‌ها: اندازه‌ها، سختی مرحله‌ها، متن اسلایدها
  logic.py              قوانین بازی (بدون pygame؛ قابل آزمون)
  persian.py            نمایش درست متن فارسی (شکل‌دهی حروف، راست‌به‌چپ، اعداد)
  graphics.py           تصویرها: جزیره، مخزن، هواپیما، پدافند (همه با کد کشیده می‌شوند)
  effects.py            انفجار، دود، جرقه، لرزش صفحه
  sound.py              افکت‌های صوتی (با ریاضی ساخته می‌شوند) و پخش موسیقی
  ui.py                 رسم متن و دکمه‌ها
  app.py                پنجره، حلقهٔ بازی، تبدیل مختصات، تعویض صفحه
  scenes/               صفحه‌ها: بارگذاری، منو، انتخاب مرحله، معرفی، بازی، نتیجه
tests/                  آزمون‌های خودکار
tools/simulate.py       شبیه‌سازی بازیکن مجازی برای سنجش سختی
tools/make_music.py     ساخت موسیقی هشت‌بیتی (theme.wav و battle.wav)
```

## نکات فنی

- **جداسازی منطق از نمایش.** `logic.py` هیچ وابستگی به pygame ندارد و فقط «رویداد» (شلیک، انفجار، آسیب مخزن، ...) تولید می‌کند؛ صفحهٔ بازی آن‌ها را به صدا و جلوه تبدیل می‌کند. به همین دلیل قوانین بدون باز کردن پنجره آزمایش می‌شوند.
- **متن فارسی بدون کتابخانهٔ اضافه.** pygame حروف فارسی را نه به هم می‌چسباند و نه از راست به چپ می‌نویسد. `persian.py` شکل هر حرف (جدا، آغازی، میانی، پایانی)، ترکیب «لا»، نیم‌فاصله و جای درست اعداد و تاریخ را خودش محاسبه می‌کند. چون بعضی نسخه‌های موتور متن pygame خودشان ترتیب حروف عربی را عوض می‌کنند، بازی هنگام شروع با دو حرف آزمایشی این رفتار را تشخیص می‌دهد و خروجی را مطابق آن تنظیم می‌کند (`Text.calibrate`).
- **یک بوم ثابت.** همه‌چیز روی بوم ۱۲۸۰×۷۲۰ رسم می‌شود و در هر فریم با حفظ نسبت به اندازهٔ پنجره یا گوشی تغییر اندازه می‌دهد؛ مختصات ماوس و لمس هم به همان بوم برگردانده می‌شود. برای اندروید هیچ کد جدایی لازم نیست.
- **تصویر و صدا با کد.** جز لوگو و فونت، هیچ فایل تصویری وجود ندارد؛ هواپیماها، جزیره و انفجار هنگام اجرا کشیده می‌شوند و افکت‌های صوتی (شلیک، انفجار، آژیر، ...) هم با ریاضی ساخته می‌شوند.
- **موسیقی هشت‌بیتی.** دو قطعهٔ حماسی با کانال‌های کنسول‌های قدیمی (لید مربعی، آرپژ، باس مثلثی چهاربیتی، درام نویزی) در ۱۶ میزان و در می‌ی‌ر ساخته شده است: `theme.wav` برای بارگذاری و منو و `battle.wav` از شروع معرفی مرحله تا پایان نبرد. اسکریپت `tools/make_music.py` بدون کتابخانهٔ اضافه آن‌ها را می‌سازد؛ با تغییر نت‌ها و اجرای دوبارهٔ اسکریپت موسیقی عوض می‌شود.
- **معرفی سینمایی.** نوار سینمایی، تایپ تاریخ با صدای ماشین‌تحریر، رادار و قفل هدف، هشدار با آژیر و موج انفجار، همه با کد کشیده می‌شوند.
- **صفحهٔ بارگذاری.** سیاه خالص است؛ آرم گروه از اندازهٔ کوچک با شتاب بزرگ می‌شود و پس از آن نوشته و نوار پیشرفت پدیدار می‌شوند.
- **صفحه‌ها.** هر صفحه کلاسی از `Scene` است و `App` فقط صفحهٔ فعلی را نگه می‌دارد؛ تعویض صفحه با محو کوتاه انجام می‌شود.
- **تنظیم سختی با داده.** مشخصات مرحله‌ها (فاصلهٔ ورود هواپیماها، سرعت، درصد اف-۳۵) فقط در `config.py` هستند و برای افزودن مرحلهٔ جدید کافی است یک `LevelConfig` اضافه شود.

### آزمون‌ها و سنجش سختی

```bash
python -m unittest discover -s tests -v     # آزمون‌های منطق و متن فارسی (نیازی به pygame ندارد)
python tools/simulate.py                    # شبیه‌سازی سختی
```

شبیه‌سازی هر مرحله را ۱۲۰ بار با سه بازیکن مجازی اجرا می‌کند (فقط برای سنجش تقریبی؛ بازیکن واقعی معمولاً ضعیف‌تر از این‌هاست):

| بازیکن مجازی | درصد برد مرحلهٔ ۱ | درصد برد مرحلهٔ ۲ |
|---|---|---|
| تازه‌کار | ۷۹٪ | ۳۷٪ |
| معمولی | ۱۰۰٪ | ۹۸٪ |
| ماهر | ۱۰۰٪ | ۹۹٪ |

## ساخت APK اندروید با گیت‌هاب

1. در github.com یک مخزن (Repository) تازه بسازید.
2. تمام فایل‌های این پوشه را در آن آپلود کنید. حتماً پوشهٔ `.github` هم با آن برود (پوشه‌های مخفی در بعضی سیستم‌ها دیده نمی‌شوند). با گیت:
   ```bash
   git init
   git add .
   git commit -m "بازی دفاع از جزیره خارک"
   git branch -M main
   git remote add origin https://github.com/نام-کاربری/نام-مخزن.git
   git push -u origin main
   ```
3. در گیت‌هاب به تب **Actions** بروید. ساخت خودکار بعد از آپلود شروع می‌شود (یا روی «ساخت APK اندروید» و سپس **Run workflow** بزنید). اولین ساخت معمولاً چند ده دقیقه طول می‌کشد؛ ساخت‌های بعدی با حافظهٔ نهان سریع‌ترند.
4. وقتی اجرا سبز شد، آن را باز کنید و از پایین صفحه، بخش **Artifacts**، فایل `kharg-defense-apk` را دانلود کنید. داخل این zip فایل `.apk` است.
5. فایل را به گوشی ببرید و نصب کنید (اجازهٔ نصب از «منبع ناشناس» را باید بدهید).

این APK از نوع debug است و برای نصب مستقیم و نمایش در مسابقه کافی است؛ برای انتشار در فروشگاه‌ها باید امضا شود.

### اگر ساخت خطا داد

متن کامل خطا در همان اجرا، مرحلهٔ «ساخت APK»، دیده می‌شود. شایع‌ترین علت‌ها:

- **نسخهٔ پایتون یا Cython.** ساخت pygame برای اندروید با پایتون ۳٫۱۲ به بالا و Cython نسخهٔ ۳ مشکل دارد؛ به همین دلیل فایل workflow پایتون ۳٫۱۱ و `cython<3.0` را ثابت کرده است. این دو را بالا نبرید.
- **خطای pygame در مرحلهٔ ساخت.** در `buildozer.spec` خط `requirements` را به `python3,pygame==2.6.1` تغییر دهید. اگر باز هم خطا بود، خط `p4a.branch = develop` را زیر `p4a.bootstrap` اضافه کنید.
- **برنامه روی گوشی باز نمی‌شود.** با کابل و `adb logcat -s python` خطای پایتون را ببینید.

## لوگو و نام گروه

لوگوی گروه فایل `assets/logo.png` است (با پس‌زمینهٔ شفاف) و در صفحهٔ بارگذاری و منو نمایش داده می‌شود. برای تغییر آن، فایل را با همین نام جایگزین کنید. اگر خواستید نام گروه زیر لوگو نوشته شود، آن را در `game/config.py` به متغیر `GROUP_NAME` بدهید.

فونت‌ها (DejaVu Sans) با مجوز آزاد همراه پروژه است؛ متن مجوز در `assets/fonts/FONT_LICENSE.txt` قرار دارد.
